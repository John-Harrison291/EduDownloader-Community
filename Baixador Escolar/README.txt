EduDownloader Community 3.0.0
Windows x64

O aplicativo reúne downloads, ferramentas PDF, conversões de documentos,
pré-visualização de arquivos e processamento de mídia. Use somente conteúdos
próprios ou autorizados. Os arquivos locais são processados no computador.

O portátil deve ser mantido em uma pasta com todos os seus arquivos.
DOCX e ODT para PDF requerem o LibreOffice compatível, obtido separadamente.
Consulte LICENSE e a pasta Licencas para os termos e avisos de terceiros.
